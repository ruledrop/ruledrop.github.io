FAQ

What is an agent rules pack?

A set of ready-made instruction files (Cursor .mdc rules, AGENTS.md, CLAUDE.md and GitHub Copilot instructions) that tell AI coding agents how to write code for a specific stack — so vibe-coded apps stay ship-safe.

Which tools does it work with?

Cursor, Claude Code, GitHub Copilot (chat, cloud agent and code review), OpenAI Codex, Jules, Amp and any tool that reads AGENTS.md.

How do I install a pack?

Unzip it into your project root. Each pack's README shows which files go with which tool.

Is there a free version?

Yes. The Starter Pack (a core Cursor rule plus AGENTS.md) is free and MIT-licensed on GitHub.

Are the rules up to date?

They are checked against official docs (Cursor, GitHub Copilot, Next.js 16, Supabase SSR, Godot 4.7, Shopify CLI) as of October 2026. Bundle buyers get free updates.
